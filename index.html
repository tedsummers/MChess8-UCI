MChess Pro 8.0 UCI

Native cross-platform UCI port of Marty Hirsch's 1998 M-Chess Professional 8.0, powered by 64-bit Magic Bitboards, Lazy SMP, original PRBOOK/, and full 35-set 3/4-piece DTM TB/ tablebases. MChess Pro 8.0 UCI plays roughly 150–250+ Elo stronger than the original 1998 DOS program while preserving its opening book, 3/4-piece tablebases, and evaluation character.

Key Features

  • 64-bit Magic Bitboards & 1 MB Lockless Pawn Hash Table: Preserves M-Chess Pro 8.0's evaluation character at ~2.3×+ higher speed (~1.05M nps 1T, ~4.25M nps 8T on Kiwipete).
  • Multi-Threaded Search (Threads 1–64): Persistent Lazy SMP worker pool with a 4-bucket lockless XOR transposition table (up to 4096 MB, default 512 MB).
  • Modern & Classic Books + Complete 3/4-Piece Tablebases: Ships with the modern GM/engine PRBOOK/ (128,495 positions) as default, preserves the original 1998 book in PRBOOK_1998/ (with Tournament/Wide/Broad modes and DeterministicBook), and includes all 35 sets (70 files) of TB/ DTM tablebases.
  • Tournament-Tuned Defaults & Classic Mode: Hash=512, BookMode=Tournament, Ponder=true, NullMove=true, Extensions=true, RandomLimit=0, MChess Pro 8.0 style sliders (5/4/1/4/5/2), calibrated 50% soft / 125% hard-cap UCI clock management, and an optional ClassicStyle toggle (false=modern, true=1990s MChess).

Quick Start

Extract MChess8_UCI_Package.zip, keep the binary alongside PRBOOK/, TB/, and SETTINGS.M80, and register the binary for your OS as a UCI engine in Arena, CuteChess, BanksiaGUI, Scid, or ChessBase.

Compiling from Source

All C11 source files and the Makefile are in source/. Requirements: gcc (for Linux) and optionally zig (for cross-compiling Windows and macOS targets from Linux).

cd source

# Linux 64-bit (recommended)
make linux64

# Linux 32-bit (requires 32-bit multilib gcc)
make

# Windows 64-bit & 32-bit (via zig cc)
make win64
make win32

# macOS Intel & Apple Silicon (via zig cc)
make macos

On macOS natively with Xcode/Clang, you can also compile directly:

clang -O2 -Wall -Wextra -std=c11 -pthread -o mchess8_uci uci.c board.c movegen.c eval.c tt.c book.c tb.c search.c tables.c bitboard.c
